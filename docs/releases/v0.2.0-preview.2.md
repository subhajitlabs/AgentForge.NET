# AgentForge.NET 0.2.0-preview.2

This coordinated preview adds the official `AgentForge.NET` convenience metapackage. It provides a single recommended installation while preserving the existing modular packages and public APIs.

## Install

```bash
dotnet add package AgentForge.NET --version 0.2.0-preview.2
```

The metapackage is dependency-only. It directly installs:

- `AgentForge.Hosting`
- `AgentForge.Tools`
- `AgentForge.Providers.OpenAI`

`AgentForge.Core` and `AgentForge.Abstractions` resolve transitively. The Microsoft.Extensions.AI adapter remains optional:

```bash
dotnet add package AgentForge.Adapters.MicrosoftExtensionsAI --version 0.2.0-preview.2
```

Developers may continue installing any modular package independently, including:

```bash
dotnet add package AgentForge.Hosting --version 0.2.0-preview.2
```

## Compatibility

- No runtime behavior or public API changed in this release.
- Existing package IDs and modular installation paths remain supported.
- Existing `AgentForge.Hosting` consumers do not need to migrate to the metapackage.
- `AgentForge.Adapters.MicrosoftExtensionsAI` is not included by default.
