# AgentForge.NET 0.3.0-preview.1

This coordinated preview delivers the completed Phase 3 resilience, resource-governance, provider-failure, and observability milestone across all seven AgentForge.NET packages.

## Install after publication

```bash
dotnet add package AgentForge.NET --version 0.3.0-preview.1
```

The dependency-only metapackage directly installs:

- `AgentForge.Hosting`
- `AgentForge.Tools`
- `AgentForge.Providers.OpenAI`

`AgentForge.Core` and `AgentForge.Abstractions` resolve transitively. The Microsoft.Extensions.AI adapter remains optional:

```bash
dotnet add package AgentForge.Adapters.MicrosoftExtensionsAI --version 0.3.0-preview.1
```

All modular packages remain independently installable.

## Phase 3 capabilities

- Optional whole-execution timeouts with deterministic caller-cancellation precedence across buffered, streaming, provider, tool, and completion boundaries.
- Optional execution-wide input/output character budgets, tool argument/result UTF-8 byte budgets, provider stream-event and accumulation limits, and observed provider-reported token budgets.
- Stable, sanitized provider-failure classifications with advisory transient metadata and no automatic Core or tool retries.
- Exporter-neutral BCL `ActivitySource`, `Meter`, and terminal `DiagnosticListener` instrumentation with bounded, low-cardinality, content-free dimensions.
- Deterministic streaming backpressure, provisional delta handling, early-disposal cleanup, and concurrent-run isolation.

## Compatibility

- Existing runtime interfaces, keyed `IAgent` registration and resolution, constructor overloads, buffered and streaming APIs, and package IDs remain available.
- Phase 3 public API changes are additive: immutable execution/resource/token policy values, new stable error classifications, builder methods, optional `TimeProvider` integration, and the read-only terminal diagnostic payload.
- Resource limits, token budgets, and the runtime timeout are disabled by default, preserving existing unbounded optional-policy behavior.
- The `AgentForge.NET` metapackage remains dependency-only and does not include `AgentForge.Adapters.MicrosoftExtensionsAI`.
- No mandatory OpenTelemetry SDK, exporter, persistence layer, service, or distributed infrastructure is introduced.

## Known limitations

- Cancellation is cooperative; an in-process provider or tool that ignores its token can continue working, although its late result cannot complete the execution successfully.
- Observed token budgets are retrospective and depend on valid provider-reported terminal usage; they do not estimate tokens or prevent one provider call from crossing a budget.
- Adapter limits cannot prevent allocations performed internally by an SDK before events or responses reach AgentForge.
- `IsTransient` does not establish replay safety. Durable retry and recovery remain application or workflow-owner responsibilities.
- Streaming text deltas are provisional; only `AgentRunCompleted` is authoritative.
- The OpenAI Responses surface remains experimental in the pinned OpenAI SDK and is acknowledged by a narrow provider-project warning suppression.
